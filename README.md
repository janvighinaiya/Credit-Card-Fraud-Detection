# Credit-Card-Fraud-Detection
An end-to-end ML pipeline for detecting credit card fraud in Python. Trains Logistic Regression, Random Forest &amp; XGBoost, handles severe class imbalance with SMOTE, and evaluates using precision, recall, F1-score &amp; ROC/PR-AUC — not misleading accuracy. Includes modular code, a Jupyter notebook walkthrough, and unit tests.
